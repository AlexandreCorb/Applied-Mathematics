# Alexandre Corbelli — Applied Mathematics Portfolio

Welcome to my academic and research portfolio.

I hold a Master's degree in Applied Mathematics from EPFL, with a focus on statistical modelling, machine learning, stochastic simulation, and numerical methods.

This repository brings together selected projects completed during my academic studies and research experience.

## Selected Projects

### 1. Master Thesis — Asymptotic-Preserving Finite Elements for Plasma Models

**EPFL · 2026**

Implementation in C++ using the MFEM library of a mixed finite-element scheme with Lagrange multipliers and implicit time stepping for a stiff plasma model.

The project focuses on the numerical treatment of multiscale plasma equations and the development of robust asymptotic-preserving numerical methods.

---

### 2. Gene Expression Analysis in Pediatric Hyperdiploid Acute Lymphoblastic Leukemia

**EPFL · 2025**

Statistical analysis of Affymetrix microarray data using R.

The project includes:
- Data quality control and preprocessing.
- RMA normalization.
- Differential gene expression analysis using `limma`.
- Clustering and exploratory data analysis.

---

### 3. Stochastic Simulation of Epidemic Models

**EPFL · 2024**

Implementation and analysis of stochastic epidemic models, focusing on SIR models, stochastic differential equation approximations, and Monte Carlo simulation methods.

The project includes:
- SIR models.
- Stochastic differential equation approximations.
- Monte Carlo methods.
- Importance sampling for rare-event estimation.
